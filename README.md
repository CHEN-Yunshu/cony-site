# Cony · 首尔翻译与中韩业务协调

个人品牌网站。主要业务是传媒与中韩业务，服务包括商务 / 展会翻译、中韩自媒体合作、医美预约陪同，以及色彩测试 / 妆造预约。

这版根据现有项目和 Cony 的朋友圈语气重新设计：干净的奶油白与深橄榄绿、少量阳光黄、真人生活照片。重点让访客认识她、理解服务，并带着具体日期与需求联系。

## 本地查看

```sh
python3 devserver.py 4321
```

浏览器打开 `http://localhost:4321/?lang=zh`。支持 `en / zh / ko / th`；未指定时读取上次选择或浏览器语言。

```sh
./build-preview.sh
```

生成 `preview.html`，代码和照片均内嵌，可以单独分享并离线打开。在线字体不可用时会使用系统字体。预览文件不提交 Git。

## 页面结构

首屏 → 四项服务 → 认识 Cony → 现场笔记 → 安排流程 → 常见问题 → 联系。

- 医美是四个板块之一，不把整个个人品牌包装为某家诊所。
- 现场笔记从用户提供的公开朋友圈提炼，展开阅读摘要。不假造文章链接、客户原话、效果或合作成果。
- 未核实的牌照编号、公司主体和示例联系方式默认隐藏。
- 移除旧版的焦虑营销、同行比较表和虚构客户评价。旧 key 仅保留兼容，不在页面展示。

## 联系配置

先把 `config.js` 里的微信、WhatsApp、邮箱、社交链接等换成真实值，再设置 `contactsVerified: true`。用不到的字段留空。

`legalEntityVerified: true` 只在确认运营主体名称后设置。登记号仍为 `XXX` 时，登记信息自动隐藏。

- 配置 `formspreeId`：表单真实发送，成功响应后才提示已发送。
- 未配置 `formspreeId`：按钮为「生成咨询留言」，只在本页生成可复制文字，不发送或保存到服务器。
- 服务、称呼、联系方式、具体需求必填；预约日期必填，传媒合作日期选填。
- 配置 `bookingUrl` 后显示预约链接。
- `videos` 支持 `mp4 / youtube / link`，空数组时整个视频板块隐藏。YouTube 点击后才加载。
- 现版照片明确写在 `index.html`。旧 `gallery` 数组为兼容保留，当前不控制图片；这是为了避免原来文件名和实际照片不一致。

## 回传校对表

新版完整校对表：`outputs/01a0ae37-5967-7651-8540-51b05b97a788/Cony网站新版文案校对表_2026-09-17.xlsx`。

包含 111 条页面文案和 45 条交互提示，英文、中文和韩文三语言并排。Cony 可直接修改 C–E 列、在 F 列标记进度、G 列留备注。泰语不参与本次校对，网站泰语保持。不要改 A 列 key；需要清空文案时整格写 `［删除］`，空白默认保留原文。`［换行］` 等标记会在回填时还原为网页格式。

```sh
python3 apply-proofread.py 回传的文案.xlsx --dry-run
python3 apply-proofread.py 回传的文案.xlsx
./build-preview.sh
```

新版 Excel 内含隐藏的版本基准，只应用 Cony 实际修改的内容；若网页在导出后又改过同一条，导入器会报告冲突并跳过，防止静默覆盖。页面文案回填 `i18n.js`，交互提示回填 `app.js`，写入前分别备份。导入器按第 5 行表头识别语言，兼容三语言和原四语言新版表。校对状态与备注供人工审阅，不直接变成网页文字。

旧版 `文案校对表_Cony网站.xlsx` 仍保留，回传后也可导入；它继续使用 `content/proofread-baseline.json` 的旧表基准。请优先使用新版表，避免重复修改两份文案。

## 设计与交互

颜色：纸白 `#F6F5EE`、墨绿 `#273B30`、深绿区块 `#344638`、淡黄 `#EEEBC9`。英文字体 DM Sans / DM Serif Display；中文、韩文与泰文使用对应 Noto Sans，未加载时有系统回退。

动画为一次性淡入、8px 内轻视差、按钮与线条反馈、FAQ 和笔记展开。无滚动劫持；遵守 `prefers-reduced-motion`。照片弹窗使用原生 dialog，支持 Esc、焦点恢复与背景滚动锁定。
