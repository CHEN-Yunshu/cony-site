# Cony 个人网站

面向澳洲 / 东南亚新市场的获客落地页。唯一 KPI 是**加到私域的人数**——网站不成交，微信/WhatsApp 里才成交。

## 文件说明

| 文件 | 用途 |
|---|---|
| `index.html` | 网站本体（单文件，无需构建） |
| `config.js` | **唯一需要编辑的文件** — 联系方式、执照号、数据 |
| `assets/` | 图片：`portrait.jpg`（首屏）、`about.jpg`（关于我）、`wechat-qr.png` |
| `build-preview.sh` | 生成 `preview.html` 单文件版，用于分享预览 |

本地查看：双击 `index.html`。或跑 `python3 -m http.server 4321 --directory .`

## 上线

推荐 **Cloudflare Pages** 或 **Netlify**：把整个文件夹拖进去就好，免费，自带 HTTPS，全球都快（中国大陆访问也比 Vercel 稳）。

域名建议 `.com`，用 Cony 的英文名或品牌名，短、好拼、好在 Instagram bio 里念出来。

## 动效与交互

全部原生实现，没有引入任何动画库。

| 效果 | 说明 |
|---|---|
| 逐行遮罩出现 | 标题按 `<br>` 切行，从下往上推出，像油墨压上纸面 |
| 译注（`.gloss`） | 每个章节小标旁挂一行另一种语言 —— 她的职业就是站在两种语言之间，让这件事在版面上看得见。当前语言是韩语时自动改挂英文 |
| 航线流程图 | 「流程」段上方一条航线弧线，五个节点对应五步，可点击跳转；滚到哪一步对应节点就亮。她的客人是飞过来的，所以流程画成一段航程，不是循环图 —— 这是单向旅程，画成环会传达错误信息 |
| 小飞机 | 8 秒飞完全程、无限循环；两端淡入淡出，所以回到起点的那一帧看不见接缝。**飞机画在节点之前**，节点盖在它上面 —— 否则飞机停在终点会把「05」盖掉一半，剩下的笔画看起来像个笑脸。减弱动效时停在巡航段中点，不压节点 |
| 时间轴 | 五步一次全部可见、可扫读。**曾经做过钉住式滚动，已拆除**：它劫持滚动、5 条短内容撑不满 4 屏、而且没法一眼看完 |
| 手绘圈 | `100+` 上一道手绘感的圈，随数字一起画出来 |
| 印章 | 登记卡片上一枚 LICENSED 印章（自己的样式，不模仿官方印） |
| 手机导航 | 绝对定位下拉面板 + 汉堡变叉的形变；点链接、点外面、按 Esc 都会收起 |
| 触屏按压反馈 | `@media (hover:none)` 下所有可点元素都有按下态 —— 触屏没有 hover，没反馈用户不知道点没点到 |
| 表单校验 | 空字段抖一下 + 跟着语言走的提示；提交时按钮自己变成进度条。表单加了 `novalidate`，校验由我们接管，否则浏览器原生气泡会抢先且不跟随语言 |
| 骨架微光 | 照片没到位时是缓慢的微光，不是一块死色 |
| 照片井 + 视差 | 「关于我」左栏三张照片，滚动时各自以不同速率位移做出景深，点击可放大。位移幅度按图片高度推算，永远小于放大 16% 留出的余量，否则小图会露边 |
| 年份轴 | 左栏时间线，读到哪一段对应年份就亮 —— 她的故事本来就是一条时间线 |
| 照片显影 | 从下往上揭开 + 由褪色回到全色 |
| 数字跳动 | 只跳 `100+`，年份不跳（跳年份很怪）。带防重入，不会卡在中途值 |
| 活的纸纹 | 颗粒层缓慢位移，模拟未涂布卡纸 |
| 手风琴 | `grid-template-rows: 0fr → 1fr`，唯一能干净动画高度的写法 |

**无障碍**：全站尊重 `prefers-reduced-motion`；另有 2.6 秒兜底，万一 IntersectionObserver 没触发也不会把内容挡住。

## 对比度

豆绿区块用的是 `--sage-block #59614C`，不是名片上那个浅豆绿。
原因：`#EFEBE0` 压在浅豆绿 `#8E9678` 上只有 **2.6:1**，远低于 WCAG AA 要求的 4.5:1，字会看不清。
现在主文字 5.4:1、次级文字 4.7:1。浅豆绿只留给不承载正文的色块。

**改配色时务必重算对比度**，不要凭眼睛。

## 视频

`config.js` 的 `videos` 数组，支持三种：

- `type:'mp4'` —— **首选**。自己托管，全球都能看，不跳走。竖屏 9:16，每条压到 5MB 内
- `type:'youtube'` —— 点了才加载 YouTube，不点就不发请求，页面更快
- `type:'link'` —— 外链卡片。**小红书只能用这种**：它没有对外 embed 接口，页面也禁止 iframe 嵌套

留空数组时整个板块自动隐藏。

> 注意：澳洲和东南亚的访客基本没装小红书，外链过去大概率打不开。国际站建议走 mp4 或 YouTube。

## 设计规范（后续新增页面请沿用）

取自 Cony 的名片：哑光豆绿卡纸 + 深墨色 + 极简无衬线。

```
--paper     #EFEBE0   纸面底色
--paper-2   #E6E1D3   次级底色
--sage      #8E9678   主色块
--sage-deep #5E6650
--sage-dark #2E3428   页脚
--ink       #1B1D17   正文
--muted     #6E7063   辅助文字
```

字体 Instrument Sans + Noto Sans SC / KR / Thai，标题字距 -0.03em，圆角 2px，不用阴影。
韩文和泰文有单独的字距与行高规则（`:lang(ko)` / `:lang(th)`），改样式时别覆盖掉。

## 品牌名 vs 公司名

网站/域名/IG 用**独立品牌名**，不用公司名（品高国际商务服务公司 · 핀고여행사）。
公司主体只出现在页脚（`config.js` 的 `legalEntity`）和医院合作页，用于核验资质。
